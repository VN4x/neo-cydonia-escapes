# Neo-Cydonia Escapes

Role: Lead UI/UX Designer & Concept Artist

Task: Create a high-end, cinematic sci-fi luxury travel landing page for "Neo-Cydonia Escapes" set on a Martian colony.

Visual Hero Composition:

- The top 60% of the viewport is dominated by a breathtaking, cinematic first-person view looking up through the hazy, terraformed copper-violet atmosphere of Mars. 

- A massive, prominent celestial planet (Venus or a high-resolution Earth) looms realistically close in the alien sky, casting subtle atmospheric scattering effects.

- In the mid-ground sky hangs one of Mars' moons (Phobos). Encircling this moon is an immense, glowing holographic/electronic LED ringscreen structure—styled like Saturn's rings. 

- This LED ring screen is actively illuminating the night sky, casting neon-gold and cyber-amber ambient light. The screen dynamically scrolls with ticking digital timestamps, glowing hyper-futuristic alien glyphs/symbols, and fluctuating flight destination names (e.g., "HELLAS DOME // OLYMPUS CALDERA").

UI & Layout Architecture (Glassmorphism & Cyber-Minimalism):

- Navigation Bar: Ultra-thin, floating crystalline header containing a minimalist logo, a live scrolling status ticker, and an glowing "Connect Wallet" capsule button.

- Hero Typography: Bold, elegant futuristic typography (similar to Orbitron, Syne, or Space Grotesk) reading "NEO-CYDONIA ESCAPES" with a glowing drop-shadow. 

- Call to Action (CTA): A prominent, interactive booking console card centered over the atmospheric landscape. The card features glassmorphism (frosted glass, semi-transparent blur, sharp neon-gold borders) and contains dropdown fields for: [Select Astro-Cycle], [Select Gravity Preference], and a bright, pulsating button labeled "LAUNCH ITINERARY".

- Color Palette: Deep space obsidian backgrounds (#0B0B0F), dusty Martian rust accents (#B85A38), neon gold (#FFC107), and holographic cyan highlights (#00F0FF).

Design Style & Quality:

- Cinematic, dark mode UI, premium sci-fi aesthetic, sharp vector layouts, autolayout ready, responsive screen parameters, clean hierarchy, interactive hover states mapped visually.
